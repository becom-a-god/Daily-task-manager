Daily Task Manager

This is a simple project to manage daily tasks.

You can add new tasks, search for existing tasks, and delete them. You can also mark tasks as completed. Completed tasks are shown in the Completed Tasks section, and all created tasks are shown in the Total Tasks section.

Technologies Used

- Python (Flask)
- HTML
- CSS
- SQL (SQLite)

Why I Built This Project

I built this project for practice. I wanted to see if I could connect Python, SQL, HTML, and CSS together to create something that actually works.

It was a good way to test what I have learned so far.
